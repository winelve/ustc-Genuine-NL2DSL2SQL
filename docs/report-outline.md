## 全篇主线（一句话，其余章节都为它服务）

**在强推理骨干上，外部脚手架（规划层、知识、检查器）的价值不取决于内容质量，
而取决于它介入时决策是否已被锁死。**

四组发现在主线上的位置：

| 发现 | 位置 |
|---|---|
| 自由文本 plan 层在 thinking 骨干上 ±0 | plan 过早锁死决策 |
| 同一份知识三点曲线（plan 后 ±0 / 声明层前 +4.81 / 裸直出 +8.66） | 知识必须抵达未锁死的决策点 |
| DSL 声明层有效（LOO 最大最显著的一刀，−14.42，p=0.0015） | 把决策显式暴露成可重开的槽位 |
| 修复环是语义纠错而非语法救护（-r0 臂 VA 几乎不掉、EX 净丢 11 题） | 顶动的是已声明但未固化的口径 |

## 2 方法（2.5 页，只写"是什么"，每小节 ≤ 半页，细节推附录）

## 3 实验（3.5 页，按真实时间线讲）

- **3.0 Setup**：数据/指标/骨干/temp 0；统计协议（逐题 match → 翻转 → 精确
  McNemar；1 题≈0.96pp；|净差|≤3 记噪声）；噪声地板 = 满配重跑空对照（待补）。
  复算命令指附录。
- **3.1 起点——复现 plan 路线及其失效**：direct 40.38 → plan 40.38（+8/−8,
  p=1.00）；两行表（pro 非 thinking +7.69 vs pro-t ±0）并置 OraPlan 去 planner
  −7.70 → 替代关系假说。紧跟边界句：两点观测支持的假说，非定律，未在 GPT-5 复现。
- **3.2 主实验——加法阶梯**：ABLATION §3 全表 + 累计口径（p=0.00016）+
  外部对照（带 caveat：dev≠test、骨干不同）+ 一句成本（去 plan 涨分又降本）。
- **3.3 机制分析（全篇重点，篇幅 ≥ 3.2）**：
  (a) 三点曲线；(b) 次可加性自检（40.38+8.66+12.50=61.5 vs 实测 57.69，
  重叠 −3.8 → 曲线不能读成"越早越好"，防吹保险）；(c) 弃疗实锤（considered
  承认看到、仍判 displaced=false 的 trace）；(d) C6 顶动案例 #24/#25/#41 逐轮
  trace、0 有害；(e) -r0 的 VA 100→99.0 但 EX 净丢 11 题。收束到"决策锁死"假说。
- **3.4 消融——LOO 减法**：ABLATION §3b 表；与加法阶梯互为交叉验证；排序不一致
  的原因（−声明层是 bundle 移除非单组件）；预先声明主检验（满配 vs 全裸、
  满配 vs plandsl），其余标 exploratory。
- **3.5 负结果（与正结果同等排版）**：画像轴判负（给知识不强制＝漏）、约定注在
  plan 后 ±0、C7 负期望。明说：这不是失败清单，是"时机>内容"的证据链。
- **3.6 泛化**：zh_dev 62.50 + 直出基线（待补）+（预算允许）zh_dev 机制曲线两臂；
  en_train 上 no-plan 不复现（+27/−24, p≈0.78）→ 诚实读数："plan 负资产"依赖
  dev 错误画像。**不放满配@en_train**（见下方红线③）。
