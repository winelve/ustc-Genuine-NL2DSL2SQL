# CHESS-IR VE2 Implementation Plan

**Goal:** Fix value pollution and restore CT-3 sample rows while preserving the
v1 experiment.

**Architecture:** Add a versioned retrieval strategy and an additive renderer.
Register two new Direct models that consume a separately generated fixed VE2
artifact. Reuse current keyword/index files and the local MPNet encoder.

**Tech Stack:** Python, pytest, SQLite, SentenceTransformers, MinHash/LSH.
